╔════════════════════════════════════════════════════════════════════════════╗
║ SECTION 1: FUNCTIONAL FORM TESTS                                          ║
╚════════════════════════════════════════════════════════════════════════════╝

PURPOSE: Verify that the linear specification is correct
QUESTION: "Is the linear functional form appropriate for the data?"

TEST 1.1: RAMSEY RESET TEST
───────────────────────────────────────────────────────────────────────────
What it tests: Whether higher-order polynomial terms should be added
How it works: Fits auxiliary regression with powers of predicted values
H0: Linear model is correct
H1: Non-linear terms needed

Interpretation:
  • p > 0.05: Linear form is correct ✓
  • p ≤ 0.05: Should consider non-linear terms or interactions ✗

Remedies if fails:
  • Add polynomial terms (x², x³)
  • Add interaction terms
  • Transform variables (log, square root)

TEST 1.2: RAINBOW TEST
───────────────────────────────────────────────────────────────────────────
What it tests: Whether specification is consistent throughout sample
How it works: Compares fit in early vs. late parts of sample
H0: Model specification is constant over time
H1: Structural break or specification change

Interpretation:
  • p > 0.05: Specification is stable ✓
  • p ≤ 0.05: Possible structural break ✗

Remedies if fails:
  • Split sample analysis
  • Test for specific break date
  • Add dummy variables for regime changes

TEST 1.3: LINKTEST
───────────────────────────────────────────────────────────────────────────
What it tests: Specification via auxiliary regression on predicted values
How it works: Regresses y on ŷ and ŷ²
Expected: β₁ ≠ 0 and β₂ ≈ 0 (significant fitted value, insignificant squared)

Interpretation:
  • β₁ significant, β₂ insignificant: Specification correct ✓
  • Both significant: Potential specification error ✗
  • Neither significant: Model needs revision ✗

WHY FUNCTIONAL FORM MATTERS:
  • Linear OLS assumes relationship is y = β₀ + β₁x + ε
  • If true relationship is non-linear, estimates are biased
  • Wrong functional form → incorrect predictions
  • Can affect hypothesis tests and confidence intervals

╔════════════════════════════════════════════════════════════════════════════╗
║ SECTION 2: HETEROSKEDASTICITY TESTS                                       ║
╚════════════════════════════════════════════════════════════════════════════╝

PURPOSE: Verify that error variance is constant across observations
QUESTION: "Does prediction error magnitude stay constant or vary?"

TEST 2.1: BREUSCH-PAGAN TEST
───────────────────────────────────────────────────────────────────────────
What it tests: Whether variance changes with regressors
How it works: Regresses squared residuals on regressors
H0: Homoskedastic (constant variance)
H1: Heteroskedastic (variance changes)

Interpretation:
  • p > 0.05: Constant variance ✓
  • p ≤ 0.05: Variance is not constant ✗

TEST 2.2: WHITE'S TEST
───────────────────────────────────────────────────────────────────────────
What it tests: General heteroskedasticity (includes squared terms, interactions)
How it works: More flexible version of Breusch-Pagan
H0: Homoskedastic
H1: Heteroskedastic

Interpretation:
  • p > 0.05: No heteroskedasticity ✓
  • p ≤ 0.05: Heteroskedasticity present ✗

WHY IT MATTERS:
  • Heteroskedasticity makes standard errors incorrect
  • T-statistics and confidence intervals unreliable
  • Coefficients still unbiased, but inference is wrong
  • Affects hypothesis testing

Remedies if fails:
  • Use robust standard errors (HC3, HC4)
  • Weighted least squares (WLS)
  • Transform variables

╔════════════════════════════════════════════════════════════════════════════╗
║ SECTION 3: NORMALITY TESTS                                                ║
╚════════════════════════════════════════════════════════════════════════════╝

PURPOSE: Verify that residuals are normally distributed
QUESTION: "Do errors follow a bell curve?"

TEST 3.1: JARQUE-BERA TEST
───────────────────────────────────────────────────────────────────────────
What it tests: Skewness and kurtosis of residuals
How it works: Combines tests for skewness and excess kurtosis
H0: Residuals are normally distributed
H1: Residuals deviate from normality

Components:
  • Skewness: Asymmetry (0 = symmetric)
  • Kurtosis: Tail weight relative to normal (0 = normal)

Interpretation:
  • p > 0.05: Residuals are normal ✓
  • p ≤ 0.05: Residuals deviate from normality ✗
  • Skewness |x| > 0.5: Significant asymmetry
  • Kurtosis |x| > 1: Significant departure

TEST 3.2: SHAPIRO-WILK TEST
───────────────────────────────────────────────────────────────────────────
What it tests: Normality of residuals (alternative approach)
How it works: Tests ordering of residuals
H0: Residuals are normally distributed
H1: Residuals are not normal

Interpretation:
  • p > 0.05: Normal ✓
  • p ≤ 0.05: Not normal ✗

WHY IT MATTERS:
  • OLS inference assumes normal errors (for hypothesis tests)
  • Coefficients are still consistent without normality
  • With non-normal errors: confidence intervals, t-tests may be wrong
  • Large samples make this assumption less critical (Central Limit Theorem)

Impact on different uses:
  • Coefficient estimation: Not needed (unbiased even without normality)
  • Hypothesis testing: Important (affects p-values)
  • Confidence intervals: Important (affects coverage)
  • Forecasting: Less critical with large samples

Remedies if fails:
  • Bootstrap confidence intervals
  • Robust inference methods
  • Check for outliers
  • Transform dependent variable

╔════════════════════════════════════════════════════════════════════════════╗
║ SECTION 4: AUTOCORRELATION TESTS                                          ║
╚════════════════════════════════════════════════════════════════════════════╝

PURPOSE: Verify that residuals are independent
QUESTION: "Are prediction errors correlated over time?"

TEST 4.1: DURBIN-WATSON TEST
───────────────────────────────────────────────────────────────────────────
What it tests: First-order autocorrelation (lag 1)
How it works: Calculates DW = Σ(εₜ - εₜ₋₁)² / Σεₜ²
Range: 0 to 4

Interpretation:
  • DW ≈ 2: No autocorrelation ✓
  • DW < 2: Positive autocorrelation (ρ > 0)
  • DW > 2: Negative autocorrelation (ρ < 0)
  • 1.5 < DW < 2.5: Acceptable range ✓

Limitations:
  • Only tests lag 1
  • Doesn't detect higher-order autocorrelation
  • Biased in presence of lagged dependent variable

TEST 4.2: LJUNG-BOX TEST
───────────────────────────────────────────────────────────────────────────
What it tests: Autocorrelation at multiple lags (1, 5, 10, 20)
How it works: Tests whether correlations are significantly different from zero
H0: No autocorrelation at specified lags
H1: Autocorrelation exists

Interpretation:
  • p > 0.05 at all lags: No autocorrelation ✓
  • p ≤ 0.05 at any lag: Autocorrelation detected ✗

WHY IT MATTERS:
  • Autocorrelation makes standard errors too small
  • T-statistics become artificially large
  • Confidence intervals too narrow
  • R² appears inflated
  • Affects hypothesis testing

Remedies if fails:
  • Add lagged dependent variable
  • Include omitted variables
  • Use HAC standard errors (Newey-West)
  • Consider ARIMA/GARCH models

╔════════════════════════════════════════════════════════════════════════════╗
║ SECTION 5: COLLINEARITY TESTS                                             ║
╚════════════════════════════════════════════════════════════════════════════╝

PURPOSE: Verify that independent variables are not too correlated
QUESTION: "Are the explanatory variables measuring different things?"

TEST 5.1: VARIANCE INFLATION FACTOR (VIF)
───────────────────────────────────────────────────────────────────────────
What it tests: Multicollinearity for each variable
How it works: VIF = 1/(1 - R²ⱼ) where R²ⱼ is from regressing j on other X's

Interpretation:
  • VIF = 1: No correlation ✓
  • VIF 1-5: Acceptable ✓
  • VIF 5-10: Moderate concern ⚠
  • VIF > 10: Serious multicollinearity ✗

What causes high VIF:
  • Variables measuring same concept
  • Correlated variables (e.g., different lags)
  • Linear combinations of other variables

TEST 5.2: CONDITION NUMBER
───────────────────────────────────────────────────────────────────────────
What it tests: Overall multicollinearity across all variables
How it works: Ratio of largest to smallest eigenvalue of X'X

Interpretation:
  • < 20: Low multicollinearity ✓
  • 20-100: Moderate ⚠
  • > 100: High ✗
  • > 1000: Severe ✗✗

WHY IT MATTERS:
  • Multicollinearity makes coefficients unstable
  • Standard errors become large
  • Difficult to isolate individual variable effects
  • Precision is lost
  • Predictions may still be OK

Remedies if fails:
  • Remove one of correlated variables
  • Use principal components
  • Ridge regression
  • Accept larger standard errors

╔════════════════════════════════════════════════════════════════════════════╗
║ SECTION 6: OUTLIERS & INFLUENCE                                           ║
╚════════════════════════════════════════════════════════════════════════════╝

PURPOSE: Identify observations that strongly affect results
QUESTION: "Are there extreme values driving the results?"

TEST 6.1: COOK'S DISTANCE
───────────────────────────────────────────────────────────────────────────
What it tests: How much each observation influences fitted values
How it works: Measures change in all coefficients if observation removed
Threshold: Cᵢ > 4/n suggests influential observation

Interpretation:
  • No obs above threshold: No influential points ✓
  • Few obs above threshold: Minor concern ✓
  • Many obs above threshold: Potential problem ✗

Test 6.2: LEVERAGE (HAT VALUES)
───────────────────────────────────────────────────────────────────────────
What it tests: Extreme values in X space
How it works: Measures how far observation is from mean X
Threshold: h > 2p/n (p = # variables, n = # observations)

Interpretation:
  • No high-leverage observations: Good ✓
  • Few high-leverage observations: Accept ✓
  • Many high-leverage observations: Investigate ⚠

WHY IT MATTERS:
  • Outliers can distort regression line
  • Extreme X values have high leverage
  • Can create spurious relationships
  • Important to check before interpretation

Remedies if problems found:
  • Investigate outliers (data error or genuine?)
  • Robust regression (less sensitive to outliers)
  • Separate analysis with/without outliers
  • Use bootstrapping for inference

================================================================================
OVERALL MODEL ASSESSMENT CHECKLIST
================================================================================

For a model to be suitable for inference and forecasting, check:

FUNCTIONAL FORM:
  ☐ RESET test p-value > 0.05 (linear form acceptable)
  ☐ Rainbow test p-value > 0.05 (stable specification)
  ☐ Linktest shows β₁ significant, β₂ insignificant

HETEROSKEDASTICITY:
  ☐ Breusch-Pagan p-value > 0.05 (constant variance)
  ☐ White test p-value > 0.05 (no heteroskedasticity)

NORMALITY:
  ☐ Jarque-Bera p-value > 0.05 (normal residuals)
  ☐ Shapiro-Wilk p-value > 0.05 (normal residuals)
  ☐ Skewness |x| < 0.5 (low asymmetry)
  ☐ Kurtosis |x| < 1 (not too fat-tailed)

AUTOCORRELATION:
  ☐ Durbin-Watson 1.5 < DW < 2.5 (no 1st order autocorr)
  ☐ Ljung-Box p-values > 0.05 at lags 1,5,10,20

MULTICOLLINEARITY:
  ☐ All VIF values < 5
  ☐ Condition number < 100

OUTLIERS & INFLUENCE:
  ☐ Few observations with Cook's D > 4/n
  ☐ Few observations with high leverage

IF ALL CHECKS PASS: Model is reliable for inference and forecasting

IF SOME CHECKS FAIL:
  • Determine which assumption is violated
  • Assess severity of violation
  • Apply appropriate remedies (robust SE, different model, etc.)
  • Document deviations from assumptions

================================================================================
SEVERITY LEVELS
================================================================================

CRITICAL (Stop and fix):
  • Functional form test fails (RESET p < 0.01)
  • Strong autocorrelation (DW < 1 or DW > 3)
  • Extreme multicollinearity (Condition # > 1000)

IMPORTANT (Address carefully):
  • Heteroskedasticity detected
  • Autocorrelation at any lag (LB p < 0.05)
  • Several influential observations
  • Multicollinearity (VIF > 10)

MINOR (Document and accept):
  • Mild non-normality in large samples
  • Slight deviations from DW = 2
  • One or two leverage points
  • Borderline VIF values

RECOMMENDATIONS FOR YOUR MODEL
================================================================================

Based on the 6-variable oil forecasting model:

Expected diagnostic behavior:
  1. Functional form: Should PASS (linear is appropriate)
  2. Heteroskedasticity: May FAIL (common in financial data)
  3. Normality: May FAIL (oil returns are fat-tailed)
  4. Autocorrelation: May have some (low serial correlation)
  5. Multicollinearity: Should be EXCELLENT (VIF < 5, Cond# ~1.7e5)
  6. Outliers: Few expected (oil prices can have jumps)

If diagnostics show issues:
  • Use robust standard errors (for heteroskedasticity)
  • Bootstrap for confidence intervals (for non-normality)
  • Add lags if autocorrelation (already has lag 2 oil)
  • Accept that financial data rarely perfectly satisfies all OLS assumptions

Key takeaway:
  • Perfect diagnostics are rare in practice
  • Use diagnostics to understand model limitations
  • Adjust methodology accordingly
  • Document any assumption violations
  • Still valid for forecasting with appropriate caveats
