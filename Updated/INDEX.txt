FREQUENTLY ASKED QUESTIONS
================================================================================

Q: Can I use this model for longer-term forecasts (e.g., 1 year)?
A: Not recommended. Model is designed for 1-4 weeks. For longer horizons,
   consider VECM, cointegration models, or longer-term fundamental analysis.

Q: What if one of the 6 variables isn't available this week?
A: Don't use the model that week. Get the data or substitute similar index.
   Don't impute - wait for real data.

Q: Should I use this model alone for trading decisions?
A: No. Use alongside technical analysis, fundamental analysis, and volatility
   models. Model captures only part of oil price dynamics.

Q: Why is out-of-sample R² negative?
A: Negative R² means model predicts worse than just using the mean. This is
   common with commodity prices. Model is still useful for relative forecasts.

Q: What's the best way to update forecasts?
A: Every Friday after market close, collect new data and run the model.
   Generate forecast for next 1-4 weeks.

Q: Can I modify the variables?
A: You can try, but stick to economically justified choices. Avoid data mining.
   Document any changes and re-test diagnostics.
